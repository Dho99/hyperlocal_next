# UI Audit 001 - 2026-11-19

Scope: admin settings and EXIF photo-validation controls requested for SAFAR.

## Findings

### 1. Global EXIF validation setting is missing

- **Priority:** MEDIUM
- **Rule:** R-26, interactive controls must perform the requested action.
- **Evidence:** `/settings` currently links only to Profil Admin and Bobot Scoring ACES-H. `app/api/upload/route.ts` always extracts EXIF and evaluates photo validity. `lib/services/destination-service.ts` also validates image metadata during destination create/update. No persisted global switch currently controls these paths.
- **Fix:** Add persisted `isExifValidationEnabled` setting with an admin switch on `/settings`; use it in upload and destination-save validation paths, with a safe default that preserves current behavior.

## Follow-up

- **Finding #1: RESOLVED.** Added the persistent admin switch, applied it to upload extraction and destination create/update validation, and kept the default enabled.
- **Verification:** `npm test` (143 tests), `npx tsc --noEmit`, focused ESLint, `npm run build`, and `npx prisma migrate status` passed. The new admin settings API returns 401 without an admin session.
